# Meridian People Analytics

An HR analytics dashboard for a fictional UAE healthcare group. It covers headcount, attrition, recruitment, onboarding, licence compliance and engagement for one hospital and eight clinics (~1,200 staff).

> **Synthetic data, portfolio project.** Meridian Health Group, its sites and every person in it are generated by `scripts/generate-data.ts`. Nothing here is real employee data.

## What it shows

| Page | Contents |
| --- | --- |
| Overview | Six KPIs with deltas and sparklines, headcount trend, hires vs exits, attrition by department, items needing attention |
| Workforce | Composition by site, department, nationality and gender; tenure; employee directory with search, sort, column picker and CSV export |
| Attrition | Exits per month (voluntary/involuntary), rolling 12-month rate, exit reasons, department × site heatmap, first-year attrition by hire cohort |
| Recruitment | Hiring funnel, source effectiveness, time to hire by department, open requisitions with SLA ageing |
| Onboarding & Compliance | New-joiner checklist status, licence and malpractice expiry buckets (overdue / 30 / 60 / 90 days), ILOE registration |
| Engagement | Pulse score and eNPS trend, score by site with outlier detection, 1-on-1 coverage by site and manager |
| Insights | Five analyst findings, each with live figures, a supporting chart and a recommended HR action |

Global filters (date range, site, department) sit in the top bar, are stored in the URL (`?from=2025-10&to=2026-09&site=nahda&dept=nursing`) and apply to every page. Press **⌘K / Ctrl+K** to jump between pages or search employees.

## Key insights (default view: Oct 2025 – Sep 2026)

1. **Nursing attrition runs at about 1.8× the rest of the workforce.** Nurses are about a third of headcount but half of all exits, and workload/burnout and pay are the leading reasons.
2. **Voluntary exits more than double in June–August.** The three summer months produce close to half of resignations, driven by relocation and family reasons.
3. **Al Nahda clinic (Sharjah) is the outlier.** Lowest engagement score (about 17 points below other sites and falling), lowest 1-on-1 coverage and roughly double the attrition of the rest of the group.
4. **Employee referrals convert around 8× better than job boards** and fill roles faster. Referral hires are also less likely to leave in their first year.
5. **Credential renewals are a capacity risk.** Dozens of licences and malpractice policies are lapsed or due within 30 days, over-represented in the MOHAP-regulated Sharjah clinics.

The exact figures are recomputed from the data and filters on the Insights page.

## KPI definitions

All calculations live in [`lib/metrics.ts`](lib/metrics.ts) as pure functions and are unit-tested in [`lib/metrics.test.ts`](lib/metrics.test.ts).

| KPI | Formula |
| --- | --- |
| Headcount | Employees on payroll at the period end, after that month's exits |
| Average headcount | Mean over the period of each month's (opening + closing headcount) ÷ 2 |
| Attrition rate (annualised) | Exits in period ÷ average headcount × (12 ÷ months in period). For a 12-month window this is the TTM rate |
| Voluntary / involuntary rate | Same formula using voluntary or involuntary exits only |
| Exits in first year | Leavers with tenure < 12 months ÷ all leavers in the period |
| First-year attrition (cohort) | Hires in a quarter who left within 365 days ÷ hires in that quarter |
| Time to hire | Days from the hired candidate's application to offer acceptance (mean of hires accepted in the period) |
| Time to fill | Days from requisition opening to offer acceptance |
| Offer acceptance rate | Offers accepted ÷ offers decided (accepted + declined) |
| Source conversion | Hires ÷ applicants, per source, for requisitions opened in the period |
| Onboarding completion | Checklist items completed ÷ items required, for joiners who started in the 90 days to the period end |
| Compliance items at risk | Licences and malpractice policies expired, or expiring within 30 days, with no renewal on file, as at the period end |
| Expiry bucket | Days to expiry: < 0 overdue; 0–30; 31–60; 61–90; > 90 valid |
| ILOE registration | Employees registered for the Involuntary Loss of Employment scheme ÷ current employees |
| Pulse score | Response-weighted mean of the 0–100 engagement index |
| eNPS | % promoters (9–10) − % detractors (0–6) |
| 1-on-1 coverage | Direct reports with ≥ 1 logged 1-on-1 in the month ÷ all direct reports |

Deltas compare with the previous period of equal length (or the previous survey/month where noted). If that period falls before the data starts, no delta is shown.

## The data

`npm run generate-data` writes typed JSON into [`/data`](data) from a seeded [`@faker-js/faker`](https://fakerjs.dev) instance (seed `202`, overridable with `SEED=`). It is a month-by-month simulation, not independent random tables:

- Exits are drawn from hazards that depend on department, site, tenure, hiring source and season.
- Each exit (and each growth role) opens a requisition. Its simulated candidate funnel produces the replacement hire, so recruitment, hires and headcount agree.
- Snapshots, onboarding checklists, credential renewal cycles, ILOE status, pulse surveys and 1-on-1 logs are all derived from the same simulated population.

| File | Contents |
| --- | --- |
| `employees.json` | ~1,650 current and former employees: role, department, site, nationality, gender, dates, status, salary band, manager, tenure, source |
| `snapshots.json` | 24 months × site × department: headcount, hires, voluntary/involuntary exits, exit reasons |
| `requisitions.json` | Requisitions with stage timestamps, per-source funnel counts, offers and hire details |
| `onboarding.json` | Joiner checklists (documents, biometric access, medical insurance, malpractice insurance, licence activation) |
| `compliance.json` | Licence and malpractice renewal cycles; ILOE registration |
| `engagement.json` | Quarterly pulse results by site × department; monthly 1-on-1 logs per manager |

## Tech stack

Next.js 15 (App Router, static export) · React 19 · TypeScript (strict) · Tailwind CSS v4 · shadcn/ui (Radix) · shadcn charts (Recharts) · TanStack Table v8 · lucide-react · Geist Sans/Mono · date-fns · Vitest

## Run it

```bash
npm install
npm run dev            # http://localhost:3000
npm test               # metric unit tests
npm run lint           # ESLint, zero warnings allowed
npm run build          # static export to /out
npm run generate-data  # regenerate /data
```

## Deploy (Netlify)

`netlify.toml` is included: build command `npm run build`, publish directory `out`. Connect the repository in Netlify and deploy; no server configuration is needed.

```
components/shell/    sidebar, top bar, command palette
lib/metrics.ts       KPI calculations (pure, tested)
data/                generated JSON
scripts/             data generator
```
